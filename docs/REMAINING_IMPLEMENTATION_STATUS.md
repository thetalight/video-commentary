该表原批次没有新增模型；后续用户明确批准的Qwen3-TTS 1.7B CustomVoice/MLX已安装并做虚构短句合成，见[QWEN_TTS.md](QWEN_TTS.md)。除该批准模型外没有新增、下载或调用模型，没有调用真实API或制作任务视频；仅代码、离线mock与合成音频测试。不可将本表视为真实整集验收。

## 已接入（待实际应用验收）

- schema-v2独立证据、画面候选和必保区间，显式旧稿迁移（P1前批）。
- 声音归属：audio_owner可为narration、original_dialogue、original_action、silence；省略保持旧v2旁白默认与revision序列化兼容。人工切换并重评，不让AI修稿偷偷改归属。
- 原声/留白仅单一连续源区间、与源区间等长，旁白必须为空。原声对白须完整包含所有所引字幕窗；这不保证ASR时间已精确到词，不能宣称所有对白绝不切字。没有源音轨的原声段报错。
- 有意静音区间在BGM混入后再次静音，不由BGM填满。最终静音检查仅在旁白字幕覆盖处阻断；原声内容与留白仍需人工听审。
- 完整旁白试听：preview_episode_narration使用同一配音缓存，拼成WAV，记录正文revision和音色。仅旁白顺序试听，不含原声/留白占位，不是最终混音预览。
- 渲染分段缓存：stage_manifest记录输入指纹、实现版本、文件大小/mtime，复用还要求媒体可读、48kHz立体声和时长检查。音轨内容/源revision/剪辑决定/画幅/原声音量变化使片段失效；只改BGM或末级字幕不重复文本AI/分段剪辑。中断重试仍新建run，但复用有效clip，缓存不在成功收尾删除。
- 本机切点候选检测：FFmpeg scene>0.35并取真实pts_time，显式按钮触发，不调用模型。按源身份缓存scene-index.json。仅候选列表，不是真剧情镜头、不是完整VFR帧索引，不自动吸附边界，不分析无对白含义。
- 逐区间排除确认：exclusion-choices.json绑定字幕revision与候选指纹；可确认/撤销各候选，材料变化后旧稿拒用。字幕或规则变更后旧选择报失效，重新确认，不静默套用。
- 统一方案JSON编辑：保存需当前正文revision与expected_story匹配，验证事件/节点覆盖；失效旧评审与输出，不自动重写正文。
- 内部timeline.json：记录输出时钟、声音归属、明确剪辑、音频位置、BGM、静音范围与估时字幕方法。当前由edit-plan导出，FFmpeg仍消费同一内存edit-plan与设置；尚未实现独立timeline导入、多渲染后端或剪映工程。
